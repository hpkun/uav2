# Legacy Persistent research archive

This tree preserves the original Persistent V1/V2 environment, modular MAPPO,
research modules, historical configurations, tools, tests, and README for provenance.
These are historical source materials, not supported entry points. Their original
imports and relative paths are retained for traceability; they are not compatible
with the formal single_round_v1 factory and cannot be run against it. Reproduce
historical studies from the Git revision preceding this migration instead.
Formal pytest collection is restricted to the top-level tests directory.
